Программа на Python для моделирования кинетики сложной химической реакции (последовательно-параллельная схема A → B → D и A → C). 

Были  решены системы ОДУ методом Рунге-Кутты (scipy.integrate.solve_ivp) для трех типов реакторов:
Периодический (BR) — анализ изменения концентраций и конверсии во времени.
РИС-Н (CSTR) — моделирование нестационарного режима выхода на стационарное состояние.
РИВ (PFR) — расчет профиля концентраций по длине реактора.

Результаты:
Были вычислены конверсия, выход и селективность по целевому продукту B для каждого типа реактора.
Найдено время достижения 80% конверсии для BR и PFR, стационарная конверся для CSTR.
Проведена одномерная оптимизация (scipy.optimize.minimize_scalar) для максимизации выхода B: подобраны оптимальное время реакции, время пребывания и длина трубы.
Произведено сравнение объемов реакторов при оптимальных режимах.
